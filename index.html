How it works

Each model is a single ONNX file in this repository (housing_regressor.onnx, churn_classifier.onnx). Feature engineering and standardization were built into the PyTorch models before export, so this page only turns your answers into a vector of raw numbers and one-hot columns, then calls the model.

Training code, results and figures: regression notebook and classification notebook. Regression and classification homework by Ashish Julakanti.
